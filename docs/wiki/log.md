## 2026-10-06 · update · решения после разбора первой версии

[[status]] дополнена решениями, которые определяют поведение сервера:

- **Защита вебморды:** только loopback и свой `Host`, изменяющие запросы — со своей
  страницы, всё запускающее процессы — только с `--allow-run`.
- **Выбор области** с состоянием «не выбрана»; что сервер берёт у агента, в том числе не
  объявленные публичными `config` и `collect.history`; известные ограничения формата
  агента.
- **Секреты** маскирует сервер на выходе, включая свободный текст артефактов и снимков:
  у агента `redact` нет. Признак секрета — посимвольная свёртка, а не NFKC всего текста
  (тот квадратичен и раздувает вывод).
- **Ход и итог прогона** — из итоговой строки pytest и кода выхода, разбор сверен с
  настоящим выводом pytest-xdist и pytest-rerunfailures; разбор закрывается на рамках
  FAILURES/ERRORS/краткой сводки; прогон без итога — «оборван».
- **Остановка** убивает всё дерево процессов, в том числе при выходе сервера по сигналу.
- **Параметризованные варианты** соединяются по пересечению эндпоинтов; потери записей
  агента считаются по причинам; записи от тестов вне текущих отчётов — сведение, а не
  потеря; худший статус требования — по последнему прогону, только если тот полный.

[[proposals]]: открытые вопросы — область и отчёты из корня, правило `default/default`,
текст безымянного элемента, `evidence` из `confidence`, `validate` с видом, заголовок в
генераторе, обёртка истории, проверка закрытых имён на клоне, незаписанные зависимости
сервера, Job Object на Windows, свежесть `coverage.json`, полнота внешних прогонов, отметка
МР по коду 2 и повторам.
