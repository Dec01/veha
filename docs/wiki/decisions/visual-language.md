# Решение: вебморда говорит языком сайта partest.ru

Принято 2026-10-19 человеком по макетам. До этого вебморда была неоновой изометрией.

## Что было не так

На открытии демо — 1450 связей сразу, около сорока подписей поверх сцены, связи в 17
цветах, группы в 12, домены в 6 оттенках, методы HTTP в 4. Больше 30 элементов
управления одной громкости: два переключателя и четыре кнопки в шапке, полоса фильтров,
рейл на четыре панели, док на двенадцать вкладок, карточка с пятью закладками. Зелёный
значил то «покрыто», то «консьюмер», то просто «группа».

## Решение

| | Как |
|---|---|
| Тема | токены `partest.ru/static/css/site.css` без изменений; светлая и тёмная — по `prefers-color-scheme`; системные шрифты и моноширинный |
| Цвет | только состояние эндпоинта: покрыт — акцент, частично — янтарь, без тестов — пустой контур, нет в отчёте покрытия — контур пунктиром, упал — красная рамка поверх. Всё остальное — оттенки чернил |
| Раскладка | по умолчанию 2D по ходу запроса: экраны → API по доменам → шина и сервисы → хранилища. Камеры нет |
| Связи | только у выбранного узла (при наведении — бледно); происхождение — начертанием: сплошная — снято и привязано к вызову, штрих — объявлено, точки — выведено (окно теста, «в тишине записей», логи) |
| Подписи | у того, что стоит списком, у цепочки и при наведении; длиннее колонки — обрезаются с «…», полное имя в подсказке |
| Навигация | пять разделов в шапке; подразделы — бывшие вкладки дока |
| 3D | «Объём» остаётся вторым видом в той же палитре, без свечения; «Кольцо» удалено |

Красный — только «упало». Поэтому пустое покрытие, недостающий тест-кейс и пустая клетка
матрицы методики — серые, а не красные.

## Почему так

Сайт человеку «очень лёгкий для восприятия», вебморда — «перегружена визуально». Карта
отвечает на два вопроса — где дыры и где упало, — и всё, что не отвечает ни на один из
них, отвлекает. Связи всей системы разом не читаются ни при каком оформлении: цепочка
одного узла — читается.

## Чем держится

- Цвета — переменные `style.css`; скрипты берут их из CSS, а не держат свои. Токены —
  ручная копия `partest.ru/static/css/site.css`: автоматической сверки нет.
- Происхождение связи вебморда восстанавливает по подписи ребра (`map2d.js`, `evidence()`):
  у ребра нет поля происхождения — см. [[proposals]]. Отсутствие замера («нет в отчёте»,
  «замера нет») не рисуется как отсутствие тестов.
- `map2d.js` рисует классами, без атрибута `style` (CSP вебморды).
- Внешних шрифтов и запросов нет: шрифты системные (красная линия «ноль исходящего трафика»).

## Цена

- Выведенные связи (общие пробелы, общий тест) на карте больше не видны — они в
  «Система → Связи».
- Автотестов на отрисовку нет: вид проверяется глазами на `veha demo`, в обеих темах.
